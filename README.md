# PCI dashboard — data README

## 1. Question and reader

**Question (exploratory):** *Which PCI sub-indices should provinces and cities invest in to attract businesses?*

Reader: a case-competition / research jury and policy-oriented business reader. The dashboard is descriptive and associational; it is not a causal evaluation or a government ranking.

## 3. Column dictionary

### `pci_provinces.csv`

| Column | Unit / format | Definition | Source |
|---|---|---|---|
| `province_id` | stable project slug | primary key, e.g. `ha-noi`; not an official state code | project mapping |
| `province_name` | text | province/city name used by VCCI 2025 | VCCI |
| `region` | text | broad region label for dashboard grouping; cross-region merged units marked `Đa vùng` | team classification; verify before peer analysis |
| `coastal` | 0/1 | 1 if any territory in the new province has a coastline | team-coded from old component provinces; verify GIS |
| `pci_s1` … `pci_s9` | score, 1–10 | nine PCI 2.0 component values in published order | VCCI PCI 2025 |
| `pci_total` | score, 0–100 | retained only for schema compatibility; blank because no public comparable total score was identified | VCCI PCI 2025 public dashboard |
| `pop` | thousand persons | population; store the value as published after converting persons to thousand persons | NSO/GSO; source table/year required |
| `grdp` | billion VND | GRDP total; this project expects current-price value unless `grdp_price_basis` says otherwise | NSO/GSO |
| `grdp_price_basis` | text | `current` or `constant_YYYY`; never mix bases | NSO/GSO |
| `firms_new` | enterprises (count) | newly registered enterprises in year 2025; not a rate | NSO/GSO |
| `firms_active` | enterprises (count) | active enterprises at 31 December 2025 | NSO/GSO |
| `fdi_pc` | million VND/person | optional FDI capital per resident; document whether source publishes it or the team derives it from total FDI capital/population | NSO/GSO; exact source table and formula required |
| `public_invest_pc` | million VND/person | optional public investment per resident; document price basis and denominator | NSO/GSO; exact source table and formula required |
| `budget_revenue_pc` | million VND/person | optional local budget revenue per resident; document scope and denominator | NSO/GSO; exact source table and formula required |
| `pm25_mean` | µg/m³ | annual mean PM2.5 concentration; specify monitor/model, spatial averaging method and coverage | environmental source; optional |

### `pci_bpi_2025.csv`

`province_id` and `province_name` identify one province; `bpi_private_sector_development`, `bpi_innovation`, and `bpi_total` are BPI scores on the published 1–10 scale; `source` is the publisher/source-page label; `source_date` is the retrieval date in ISO `YYYY-MM-DD` format. BPI is not part of the nine PCI component scores.

### `model_results.csv`

`outcome` is the modelled rate (new or active enterprises per 1,000 persons); `predictor` is one PCI component (score units 1–10); `model_spec` describes OLS + HC3 robust standard errors; `n` is complete-case province count; `coef` is the rate-unit change associated with a one-point higher PCI component score; `std_err_hc3` is the HC3 robust standard error in the same coefficient units; `p_value` is unitless; `r_squared` is unitless; `ci95_low` and `ci95_high` are lower/upper 95% confidence bounds in coefficient units; `interpretation` reminds that the estimate is associational.

### `vn_provinces.geojson`

Each Feature must contain `properties.province_id` (project key) and `properties.province_name` (display name); geometry is a polygon/multipolygon in EPSG:4326. Retain other source properties and attribution.


### `pci_panel_63.csv`

`province_id_old` is a project slug for an old province; `year` is calendar year; `framework_version` identifies the annual PCI framework (`PCI_legacy_YYYY` is a placeholder until the relevant report/methodology is checked); `pci_old_1` … `pci_old_10` are slots for the legacy PCI component series; `n_surveyed_firms` is respondent count if VCCI publishes it. Scores are raw published values, not z-scores. Year-specific source sheet and column headers are recorded in `config/pci_historical_column_map_template.csv`.

### `outcomes_panel_63.csv`

`province_id_old`, `year`, `firms_new` and `firms_active` are enterprise counts; `pop` is thousand persons; `grdp_pc` is million VND/person; `grdp_pc_price_basis` must state `current` or `constant_YYYY`; `source_note` records GSO table number, URL and any methodological note. Do not sum `grdp_pc` across provinces; aggregate it using population weights.

### `crosswalk_63_to_34.csv`

`old_province_id` and `new_province_id` are stable project IDs; `old_province_name` and `new_province_name` are display names; `change_type` is `giữ`, `đổi tên`, or `gộp`; `share` is the fraction of the old province's count/population assigned to the new province (1.0 for all rows in this 2025 province-level merger); `note` cites the legal basis. If a future geometry/data release indicates a split, replace the share with a documented allocation and test that all shares for each old ID sum to 1.

### `pci_concordance.csv`

`old_code` identifies a legacy concept; `new_code` identifies a PCI 2.0 component or BPI measure; `bridge_group` is a 5-theme conceptual grouping; `change_type` indicates keep/rename/merge/new; `note` states why the mapping is approximate. Do not use this file to mechanically transform historical scores into PCI 2025 scores.

### `pci_subindex_meta.csv`

`code`, `name_vi`, `name_en`, `description` describe each of the nine PCI components; `bridge_group` maps to the bridge themes; `horizon_years` (years) and `cost_level` (`low`/`medium`/`high`) are explicitly **team assumptions**, not VCCI facts. `assumption_reason` records the team's rationale.

## 5. Known issues

- **PCI survey perception:** PCI reflects surveyed business perceptions and reported experiences, not a direct objective audit of all government actions. Dashboard wording uses “perceived”, “reported” and “association”.
- **Small cross-section:** n is at most 34 provinces; show complete-case n on every chart/model and avoid overfitting.
- **Reverse causality / endogeneity:** better-performing private sectors may also shape perceived government quality; a cross-section cannot identify direction.
- **Reform lag:** policy/governance changes may take time to affect firm entry or density; `horizon_years` is a team assumption, not an estimated lag.
- **2025 framework break:** PCI 2.0 has nine new components and a different diagnostic framing; legacy PCI is not a continuous identical scale. Do not splice the series without explicit caveats.
- **Provincial mergers:** 63 old provinces became 34 from 1 July 2025. Counts/population can be aggregated through the crosswalk; PCI scores cannot be summed. Some provinces span more than one conventional socio-economic region; region grouping is a team classification.
- **GRDP price basis:** current-price and constant-price GRDP must be kept separate. `grdp_pc` is million VND/person; weighted aggregation needs compatible price basis and year.
- **Indicator definition changes:** enterprise registration/active-enterprise definitions and GSO table coverage may change. Record the exact table, reference date and unit.
- **Missing and suppressed values:** blank means unavailable/not yet verified, not zero. Never fill with zero or silently impute.
- **Index bridge is approximate:** `pci_concordance.csv` groups concepts only; it does not create cardinal equivalence between old and new scores.
- **Cost and horizon are assumptions:** `horizon_years` and `cost_level` are the team's scenario assumptions. They must be visually labelled “Giả định của nhóm”.
- **BPI only 2025:** BPI is a separate experimental measure; it is not a PCI subindex and has no legacy bridge.

## 6. What is NOT in the data

- No causal identification, treatment assignment, counterfactual or instrumental-variable design.
- No comparable 2025 PCI composite score/rank unless VCCI later releases an official comparable measure.
- No historical BPI series; BPI is available here for 2025 only.
- No firm-level microdata; no respondent-level identifiers.
- No assumed values for missing GSO variables, `horizon_years`, or `cost_level` presented as observed facts.
- No mechanical conversion of old PCI scores to PCI 2.0 scores.
